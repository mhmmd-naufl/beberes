# 05. Validasi User

Proyek ini dianggap berhasil bukan karena fiturnya banyak, tapi karena ada orang nyata yang memakainya.

## Target

- 3-5 user nyata sebelum v0.5, 5+ sebelum v1.0
- Minimal 1-3 testimoni terukur (waktu sebelum/sesudah)

## Kandidat user awal

- [ ] Pengurus/panitia kegiatan kampung
- [ ] Teman yang menjadi admin (sekolah, kantor, toko)
- [ ] Perangkat desa/RT/RW yang dikenal
- [ ] Komunitas developer lokal (untuk umpan balik teknis)
- [ ] Teman kuliah/alumni yang sering mengolah data survei

## Pertanyaan wawancara singkat (10-15 menit)

1. Kerjaan apa yang paling sering kamu lakukan di Excel?
2. Kapan terakhir kamu merapikan data? Ceritakan.
3. Bagian mana yang paling lama/menyebalkan?
4. Kesalahan apa yang pernah terjadi karena data berantakan?
5. Berapa lama biasanya waktu yang dihabiskan? Seberapa sering?
6. Bagaimana caramu merapikan sekarang? (manual, rumus, minta orang lain?)
7. Boleh lihat contoh file (disamarkan)?
8. Kalau ada alat yang merapikan otomatis, apa yang kamu khawatirkan?

## Uji coba pemakaian

1. Minta user membawa 1 file nyata.
2. Catat waktu manual (atau estimasi) vs waktu pakai beberes.
3. Amati tanpa membantu: di mana mereka bingung?
4. Tanyakan: apa yang kurang? apa yang membingungkan? akan dipakai lagi?
