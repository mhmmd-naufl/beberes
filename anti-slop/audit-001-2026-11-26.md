# Audit anti-slop 001 — 2026-11-26

Target: `src/beberes/ui/index.html` (UI lokal `beberes ui`, vanilla JS).
Mode: AFTER. Setiap temuan menyebut aturan (R-XX) dan alasan satu baris.
Prioritas mengikuti tier aturan: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

Catatan arah (R-37): tidak ada `DESIGN.md` untuk UI ini. Produk = utilitas lokal
single-purpose untuk pengguna Indonesia, jadi pembacaan yang jujur adalah
alat kerja tenang: dial ENERGY 1 / RHYTHM 1 / MOTION 1. Anggap hasil audit
sebagai draft tanpa arah formal sampai ada keputusan gaya.

Yang sudah PASS (tidak jadi temuan):
- Kontras semua pasangan terpakai >= 4.5:1 (diverifikasi contrast-check.py):
  `.muted` 4.76, `.peringatan` 5.02, `.error` 6.47, `.info` 6.70,
  tombol utama 5.47, `button.kecil` 12.67.
- Palet hemat: 1 aksen teal + netral slate (R-29 PASS).
- Tidak ada gradient, glassmorphism, glow, shadow dekoratif, background grid.
- Semua kontrol punya perilaku nyata (R-26 PASS secara fungsi).
- Escaping HTML sudah dipakai untuk data grup/audit (tapi belum konsisten, lihat #6).

## Temuan

1. **[HIGH] R-02 — Em dash (`—`) di teks UI.** Muncul di `<title>`,
   subtitle, header sheet, label grup, dan teks hasil (±6 lokasi).
   Hard Gate: dilarang di teks tulisan agen; ganti koma/titik/nokota.

2. **[HIGH] R-39 — Field form tanpa `<label>` terasosiasi.** `input[type=file]`
   dan `textarea#aturan` hanya punya `<p class="muted">` dan placeholder.
   Placeholder bukan label; tambah `<label for>` yang terlihat.

3. **[HIGH] R-03 — Tidak ada `<meta name="viewport">`.** Mobile akan render
   layout desktop yang di-zoom-out; tabel temuan 5 kolom dan tabel audit
   berisiko overflow horizontal (hanya `.scroll` yang dibatasi tingginya).

4. **[HIGH] R-26 — Tombol "semua"/"kosongkan" di dalam `<summary>`.**
   Klik tombol ikut men-toggle `<details>` induk, jadi kontrol tidak
   berperilaku sesuai maksud. Perlu `event.preventDefault()` atau
   pindahkan tombol keluar `<summary>`.

5. **[HIGH] R-39 — Dokumen utuh tanpa landmark.** Tidak ada `<main>`
   (dan `<header>` untuk judul). Satu `h1` dan `lang="id"` sudah benar.

6. **[MEDIUM] C-4 — Escaping tidak konsisten (defect, di luar tier).**
   `t.pesan`, `t.contoh`, `t.kode`, `t.kolom`, `l.sheet` dirender mentah;
   nama sheet/teks dari file pengguna bisa menyuntik HTML/JS ke UI lokal.
   `esc()` sudah ada, tinggal dipakai konsisten.

7. **[MEDIUM] R-08 — Panah `→` dekoratif di tombol "Bersihkan → unduh".**
   Panah pada contoh `lama → baru` justru bermakna (transformasi nilai)
   dan dipertahankan; di tombol tidak ada arah yang ditunjukkan.
   Saran label: "Bersihkan & unduh".

8. **[MEDIUM] Emoji 🧹 di `<h1>`.** Dekorasi emoji adalah tell umum
   (antislop-ui "Emoji as Decoration"). Bisa dipertahankan HANYA bila
   ditulis alasannya (motif sapu = "beberes"); kalau tidak, hapus.

9. **[HIGH] R-03 — `button.kecil` di bawah tap target 44px.**
   Padding `.15rem .6rem` menghasilkan tinggi ~24px. Kecil secara
   visual boleh, tapi area ketuk perlu diperbesar (min-height/padding).

10. **[LOW] R-27 — State kosong/loading belum eksplisit.** Loading ada
    teks ("memeriksa…") dan error ada, tapi `#hasil` sebelum periksa
    kosong total tanpa penjelasan, dan tidak ada `aria-live` untuk
    pembaca layar.

11. **[LOW] R-21 — Tidak ada dark mode.** Untuk utilitas lokal,
    light-default bisa dipertahankan dengan alasan tertulis, tapi rule
    meminta keputusan sadar: tetap light (alasan: alat kerja data,
    bukan produk konsumen) atau buat toggle yang benar-benar jalan.

12. **[LOW] R-39 — `cursor: pointer` hanya di `button`.** `summary`
    dan `label` (pembungkus checkbox) memakai cursor default; affordance
    klik tidak konsisten. Satu baris CSS base layer.
